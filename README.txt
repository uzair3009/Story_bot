WA Status Scheduler Bot
======================

Isi paket:
- status-bot.js (bot Baileys)
- jadwal.json (jadwalmu)
- package.json

Cara Termux (HP Android):
1. Install Termux
2. Salin 1 perintah dari tools (tombol Salin 1 Perintah Termux)
3. Tempel di Termux, Enter, tunggu, scan QR

Cara Railway:
1. Upload semua file ke GitHub repo baru
2. railway.app > New > Deploy from GitHub
3. Buka Logs > scan QR

Nomor bot: 
Jadwal: lihat jadwal.json
